# tiny-chess-01 — entry v8

Original Python chess bot for the [make.fun tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01).
Single-file engine (alpha-beta search, quiescence, PST evaluation) plus a
small verified opening book for specific house-bot matchups. main.py is a
self-extracting lzma bundle (source form kept by the author).
